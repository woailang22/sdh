# 石镐误获得伐木加成修复

在营地种植显示的原生验证中，装备pickaxe_stone的一次采集实际获得3木。equipmentRules.gatheringEffects用未锚定/axe_stone|stone_axe/匹配木材收益，pickaxe_stone包含axe_stone，因此误获石斧加成；同一工具说明却写“伐木无加成”。已有“镐不享斧收益”回归只检查采石，未检查伐木。

本项恢复已批准采集设计中斧/镐分工，不重调经济。选择两个斧ID精确相等判断，保留当前axe_stone与旧stone_axe各3木；石镐/铜镐/鱼竿/徒手各1木，镐采石3/4与矿物、鱼竿能力均原样。相比统一重构所有工具分类或改描述承认共享加成，精确匹配改动最小并符合现有说明和玩法分工。

不追溯重算既有玩家库存、不改工具成本/冷却/节点stock/刷新/持久化/原生输入。共享helper仍是服务器收益与物品说明的来源。用真实服务器action先镐采1、正常装备斧后采3、请求重放及存档恢复验证，加共享已知工具矩阵。原生同一实赚角色用现有付费镐/斧实际对照；不注入资产或重置角色。
