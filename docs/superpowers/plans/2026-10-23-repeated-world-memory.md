**Scope:** Run the approved three-repeat cache check on a real production browser/server and owned new SQLite fixture. This is a measured short route, not full-world traversal, siege capacity, an earned-economy run, long-session stability or all native input acceptance. No runtime change is proposed without a captured defect.
