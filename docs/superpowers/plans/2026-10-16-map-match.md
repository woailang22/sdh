# Map-Match Implementation Plan（预览图 = 进图所见）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 地图预览图与实际进图观感一致：地面色板按预览重调为 dusty 灰调、每主题一层尘雾罩染、切图时 2.4s 预览 splash 做心理锚点。

**Architecture:** `visualTheme.ts` 的 BASE_PAIRS 按四张预览实测取 dusty 色（checker 微差逻辑不动）+ 新增 `themeHaze(theme)`；引擎 `render()` 在 weather 后加 `renderThemeAtmosphere()` 全屏罩染；App 在 `onMapZoneChange` 弹 2.4s 预览 splash（z-40，boot z-50 之下）。

**Tech Stack:** TypeScript, Canvas2D, React, vitest

**Scope notes (deliberate):**
- themeAccent/ Fol iage /天气色不动：只改地面观感，不动 UI 与玩法可读性。
- 墙/门/地板几何、truck/van、池塘、芦苇、裂隙尖塔：无对应美术或几何承重，保持现状。
