# 《坍界行者：边缘黎明》(Rift Walker: Edge of Dawn)
## 真正多人实时联机MMORPG：领地建造、突袭攻防与野外练级体系规划方案

本方案根据您的核心指示——**“联机是重点，这是多人联机练级网游，开阔地建造领地，其他玩家可搜刮物资突袭破开安全门（耐久度与随机性），彻底去除网页Demo感”**，重塑整体架构，将游戏从单机客户端演示彻底升级为**全栈 WebSocket 权威网络驱动的真实多人联机开放世界生存练级网游**。

---

### 用户确认决策与核心机制基准 (User Review & Critical Decisions)

> [!IMPORTANT]
> **已确认核心架构与玩法基准**：
> 1. **联机是绝对核心（Multiplayer First）**：基于真实 WebSocket 服务端实现全双工网络同步，绝不使用模拟玩家或前端定时器欺骗，支持多客户端同屏跑图、组队打怪、抢夺资源与跨玩家对抗。
> 2. **领地建造与突袭攻防机制**：
>    - 玩家可在不同地图中平坦、开阔无遮挡的区域展开领地核心（Territory Core），铺设地基、防御围墙、自动哨塔与**带有独立耐久度的高级安全门**。
>    - 敌对/其他玩家可侦察偷袭敌方领地，消耗在野外危险区域搜刮的特殊破拆物资（如电磁破拆钻、聚能爆破炸药、高频撬棍）尝试暴力破解安全门，破拆过程引入物资消耗判定与随机成功率/随机暴击破损机制。
>    - 领地受袭时，所有者将收到实时红色入侵警报，可火速回防展开在线实时攻防战。
> 3. **多人练级与数值成长循环**：打怪掉落战利品与经验值（XP），等级提升赋予属性点与专精技能，形成纯正多人在线 RPG 练级快感。
> 4. **野外动态随机天气与安全区恒定晴和**：野外地图由服务端驱动随机切换（晴朗、酸雨泥泞、辐射毒雾、离子雷暴），动态改变视野范围、环境音效与光影着色；领地安全区与大本营始终保持恒定晴和。
> 5. **彻底去Demo化主机级界面**：完全清除所有浮动切图、调试天气、Demo测试按键；采用主机 3A 级别沉浸式 HUD，全局交互依赖大本营 NPC、领地工作台以及专属快捷键（`[M]`战术地图、`[B]`建造轮盘、`[C]`角色练级界面、`[I]`战术行囊、`[Enter]`联机频道聊天、`[E]`场景交互）。

### 1. 总体概念与联机核心玩法 (Overview & Core Gameplay Loop)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   《坍界行者》多人联机开放世界核心循环                      │
├────────────────────────────────────────────────────────────────────────┤
```

1. **多人联机实时同屏**：
   - 玩家进入游戏后分配独立身份（呼号、外观、职业专精），同屏渲染其他真实在线玩家的移动走位、朝向、攻击动作、血条、等级徽章与实时动作。
   - 具备全局联机电台与附近玩家频道，按 `[Enter]` 发送文字，同步展示玩家头顶冒泡气泡。
2. **开阔区域领地筑基与安全门防御体系**：
   - 地图开阔地带（平坦无掩体区域）可被标记为“可建造地块”，玩家在此放置“领地基准核心”后激活防护力场。
   - 核心建造物：钢构地基、防爆掩体、**高耐久安全防盗门（电子锁门/重装钛合金门）**、物资储物箱。
   - 安全门具有显式耐久度（如 1000/1000），只有拥有者或授权队友可自由开闭。
3. **多人突袭偷袭与破门机制（PVP/掠夺玩法）**：
   - 非领地成员接近安全门时触发“突袭破拆”交互，界面展示安全门耐久与破拆需求。
   - 玩家可选择消耗在废墟搜刮获得的破拆道具：
     - *简易破拆撬棍*：低消耗，破拆速度慢，每次消耗造成小额固定伤害。
     - *聚能塑胶炸药 / 铝热爆破剂*：稀有物资，引发爆破判定，有概率发生“完美暴击破障”直接削减大量耐久，亦有小概率“引信哑火/物资损耗”。
   - 破门成功后安全门被炸毁，突袭者可长驱直入洗劫储物箱中的未锁定物资！
   - 被突袭方的领地核心会向在线主人推送高危入侵告警，触发即时领地防卫战。
4. **野外练级打怪与资源采集**：
   - 野外异化生物（潜行感染者、重装裂隙兽、精英母巢）分布在危险废墟中，击杀获取升级经验（XP）。
   - 角色升级时升级光效全网同步广播，玩家可自由分配加点（力量/体质/敏捷/工程学），提升采集速度、突袭破拆成功率或枪械伤害。

### 3. 技术架构与全双工网络同步策略 (Technical Architecture)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        多人联机全栈系统架构                             │
└────────────────────────────────────────────────────────────────────────┘

 [客户端 Client A] (React 19)          [客户端 Client B] (React 19)
       │                                     │
       │ WebSocket (实时状态上传与渲染)       │ WebSocket
       ▼                                     ▼
 ┌─────────────────────────────────────────────────────────────────────┐
 │           Node.js / Express 全栈服务 (Port 3000 / server.ts)        │
 │                                                                     │
 │   ┌───────────────────────┐         ┌───────────────────────────┐   │
 │   │  WebSocket 房间引擎   │ <─────> │    服务端权威状态机       │   │
 │   │  (ws Server 30Hz广播) │         │  (Authoritative State)    │   │
 │   └───────────────────────┘         └───────────────────────────┘   │
 │              │                                    │                 │
 │              ├── 多玩家位置与动作插值             ├── 领地地块与结构│
 │              ├── 战斗命中与经验结算               ├── 安全门耐久与锁│
 │              ├── 突袭破门物资判定与随机计算       ├── 储物箱物资分配│
 │              └── 联机聊天消息分发                 └── 全局天气循环器│
 └─────────────────────────────────────────────────────────────────────┘
```

#### A. 服务端设计 (`server.ts`)
- **全栈一体化**：在当前项目中配置 Express + `ws` 库，在端口 3000 上统一提供 Vite 前端渲染服务与 WebSocket 实时通讯。
- **内存持久化网游状态**：
  - `players`: 记录所有在线玩家的 `id, name, level, hp, pos, currentZone, action, inventory`。
  - `territories`: 记录已建造领地 `corePos, ownerId, ownerName, structures (walls, doors, floors)`。
  - `securityDoors`: 记录安全门实体 `id, territoryId, hp, maxHp, isLocked, isBreached, breachHistory`。
  - `weatherState`: 记录各野外地图当前天气、剩余持续时间与下一阶段天气演化目标。
- **核心网络协议包规范**：
  - `join`: 玩家加入，下发完整世界快照（其他玩家、领地实体、天气）。
  - `player:move`: 客户端以 30Hz 节流上传位移，服务端广播其他玩家。
  - `combat:attack`: 玩家攻击怪物或其他目标，服务端计算命中与扣血并广播。
  - `territory:build`: 玩家在平坦开阔区域放置建筑，服务端校验无遮挡后同步全局。
  - `territory:breach`: 玩家对敌对安全门发起突袭，服务端检查其背包中破拆物资、生成随机成功判定、扣除安全门耐久并广播入侵告警。
  - `chat:message`: 玩家发言同步广播。

#### B. 客户端设计 (`src/game/` & `src/components/`)
- **网络客户端连接器 (`src/game/NetworkManager.ts`)**：
  - 自动连接当前宿主机的 WebSocket 服务，维护心跳与断线平滑重连。
  - 维持远程玩家的线性插值（LERP）渲染，杜绝卡顿瞬移。
- **等距引擎升级 (`src/game/IsometricEngine.ts`)**：
  - 支持渲染多位同屏在线玩家模型（包含装备、头顶名字、等级与动作）。
  - 实时渲染其他玩家的领地、安全防盗门耐久血条与受击破拆火花特效。
  - 昼夜光照与野外天气全屏着色器（雨水涟漪、雾霭、雷暴强光），领地内部受力场庇护保持清爽。
- **突袭破门操作面板 (`src/components/BreachModal.tsx`)**：
  - 当玩家在野外靠近其他玩家的安全门时，按 `[E]` 呼出突袭破门操作台。
  - 显示安全门当前装甲防御度与剩余耐久，列出背包内可用的破拆工具，点击进行破坏并在现场播放破拆特效与全服日志。

### 4. 实施阶段与交付路线 (Implementation Steps)

1. **第一阶段：全栈网络与实时通信基础设施构建**
   - 在 `package.json` 中配置 `ws` 与全栈启动脚本，创建 `server.ts`，打通 Express + Vite + WebSocket 服务。
   - 实现房间广播、玩家加入/离开、实时位置同步与联机电台。
2. **第二阶段：平坦开阔地领地建造与高耐久安全门系统**
   - 在世界地图中规划平坦开阔建筑区域（平原、河畔开阔地、废弃机库地基）。
   - 实现领地核心部署、安全门放置与专属耐久度数据模型，服务端全网广播已建建筑。
3. **第三阶段：野外物资搜刮与突袭破门（偷袭/随机破坏）机制**
   - 增加野外破拆物资掉落（撬棍、炸药、爆破索）。
   - 完善靠近敌对安全门时的破拆交互，服务端实现基于物资消耗与随机概率的突袭判定，支持在线警报推送。
4. **第四阶段：多人练级成长与野外动态天气演变**
   - 服务端定时演化野外地图天气系统并同步给所有客户端，安全区与领地内部维持恒定晴好。
   - 完善击杀怪物、破拆掠夺的经验获取与角色属性升级面板。
5. **第五阶段：主机级 HUD 精雕与全方位去 Demo 化验证**
   - 移除所有旧版切图与天气测试按钮，接入快捷键 `[M]`, `[B]`, `[C]`, `[I]`, `[Enter]`。
   - 整体联机调试，验证多端同屏协同与领地攻防。
